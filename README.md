## Deskripsi Tugas

Tugas ini merupakan perancangan antarmuka website **EduSmart – Platform Pembelajaran Digital** menggunakan Figma.

Pengerjaan dilakukan melalui beberapa tahap, yaitu **Wireframe (WF)**, **Mini Design System**, dan **Mockup Final (MC)**. Setiap rancangan dibuat dalam versi desktop dan mobile agar menghasilkan tampilan yang konsisten dan responsif.

Selain itu, proyek ini mencakup tiga tugas utama, yaitu Tugas Individu, Tugas Kelompok, dan Studi Kasus UI/UX.

## Alur Pengerjaan

### 1. Wireframe (WF)

Wireframe merupakan tahap awal dalam merancang struktur dan tata letak website sebelum diberikan warna dan elemen visual secara lengkap.

Bagian yang dirancang:
- Header dan navigation bar
- Hero section
- Kategori pembelajaran
- Daftar kursus online
- Card pembelajaran
- Footer

Wireframe dibuat menggunakan warna abu-abu untuk memperjelas struktur halaman.

### 2. Mini Design System

Mini Design System dibuat sebagai panduan visual untuk menjaga konsistensi tampilan EduSmart.

Ketentuan desain:
- Warna utama biru `#2563EB`
- Warna sekunder `#DBEAFE`
- Background `#F8FAFC`
- Warna teks `#1E293B`
- Font Poppins
- Spacing 8px, 16px, 24px, dan 32px
- Button dengan sudut membulat
- Form controls berupa input dan dropdown
- Cards dengan background putih dan shadow

### 3. Mockup Final (MC)

Mockup Final merupakan hasil pengembangan wireframe menjadi tampilan high fidelity dengan penerapan design system.

Komponen yang dirancang:
- Header dan navigation bar
- Hero section EduSmart
- Daftar kursus online
- Card pembelajaran
- Tombol Mulai Belajar
- Dashboard pembelajaran
- Tampilan desktop dan mobile

### 4. Studi Kasus UI/UX

Studi kasus ini berfokus pada perancangan platform pendidikan digital EduSmart.

**Permasalahan:**

Wireframe sederhana belum dapat menggambarkan tampilan akhir produk secara jelas.

**Solusi:**

Mengembangkan desain high fidelity dengan identitas visual yang konsisten, hierarki informasi yang jelas, serta penyesuaian tampilan desktop dan mobile.

**Hasil Rancangan:**
- Dashboard pembelajaran
- Informasi kursus online
- Progres belajar
- Navigasi pengguna
- Tampilan responsif desktop dan mobile

## Catatan

Pada versi desktop, EduSmart menggunakan navigasi horizontal dan susunan konten dalam beberapa kolom.

Pada versi mobile, konten disusun menjadi satu kolom dengan navigasi yang lebih sederhana serta penyesuaian ukuran tombol dan card.

Wireframe menggunakan warna abu-abu, sedangkan mockup final menggunakan warna biru dan putih sesuai dengan Mini Design System EduSmart.

Desain dibuat menggunakan Figma dan masih berupa rancangan antarmuka, sehingga belum sepenuhnya memiliki interaksi prototype.
